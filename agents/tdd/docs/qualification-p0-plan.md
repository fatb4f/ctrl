# Qualification P0: Deterministic Authority Chain

This document is the stable entry point for the P0 implementation plan. The normative plan is
organized into ordered section fragments so that each implementation boundary can evolve without
turning the plan into one monolithic file.

Read the fragments in this order:

1. [Summary and scope](qualification-p0-plan/00-summary-and-scope.md)
2. [Contracts and generated transports](qualification-p0-plan/10-contracts-and-generated-transports.md)
3. [Package and module boundaries](qualification-p0-plan/20-package-and-module-boundaries.md)
4. [Pure qualification kernel](qualification-p0-plan/30-pure-qualification-kernel.md)
5. [Providers and artifact custody](qualification-p0-plan/40-providers-and-artifact-custody.md)
6. [Minimal vertical episode](qualification-p0-plan/50-minimal-vertical-episode.md)

8. [Assumptions and deferred scope](qualification-p0-plan/70-assumptions-and-deferred-scope.md)

The fragment numbering defines document order only. It does not define runtime phases or grant
authority to prose; authored CUE and the pure qualification kernel retain the authority described
by the plan.

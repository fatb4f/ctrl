# Assumptions and deferred scope

- The fixture distribution, not `tdd-seed` production behavior, owns the example configuration
  parser and diagnostic code.
- P0 supports one pytest provider, one obligation predicate, exact replacement changes, one wheel
  format, and one local installation environment.
- Wall-clock expiry, waivers, retries, repeated-observation stability, mutation evidence, hostile
  generation, runtime observation, agents, graph orchestration, historical policy ranking, and
  `python-control` remain P1 or later.
- The existing broader qualification plan remains the long-range architecture; this document is
  its executable first slice.

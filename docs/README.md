# Documentation authority

`ctrl` documents federation assembly and supporting research. Canonical
qualification semantics and accepted architecture documents are owned by the
independently versioned `fatb4f/kernel-spec` repository.

Authority order:

1. Kernel-spec Qualification P0.
2. Kernel-spec ADR-0001.
3. Kernel-spec Assurance Runtime v0.
4. Accepted architecture research.
5. [`REFERENCES.md`](REFERENCES.md), which is supporting lineage only.

The frozen S0 implementation contract is
[`s0-semantic-consolidation-plan.md`](s0-semantic-consolidation-plan.md).
